# Everly — Wedding Planner Prototype

A responsive, front-end wedding-planning prototype designed around a Lebanon wedding workflow. Built as a zero-build static page so it can be tried quickly.

## Try it
Open [prototype/index.html](./prototype/index.html) in a browser, or enable GitHub Pages for this repository and browse to `/prototype/` if Pages is configured.

## Included screens
- **Overview** — countdown, progress, budget summary, and upcoming tasks
- **Budget planner** — editable total budget, planned category amounts, and actual spend (USD)
- **Wedding checklist** — add tasks and mark them complete
- **Vendor discovery** — sample vendor cards, search, and category filters
- **Guest list** — add guests and update RSVP status

## Run locally
No build tools or dependencies are required. Download the repository and open `prototype/index.html`.

## Notes
- This is a UI prototype, not a production application.
- Data is saved to the browser's local storage on the current device.
- Vendor names, ratings, locations, and prices are illustrative examples, not verified businesses.
- No authentication, database, live vendor contact, payments, or cloud sync is implemented yet.
- Visual style: warm ivory, forest green, muted sage, gold details, and editorial serif headings.
